# Experiment history

This is the single experiment log for Pixel Revival. Entries follow the order of the work, from the earliest surviving records to the latest. Each entry records the approach, observed result, and decision. Related retries are grouped where they answer the same question. A pass applies to the stated test, fixture, or recording. [Project flow](PROJECT_FLOW.md) describes the current implementation.

Raw captures, outputs, requests, and measurements remain in local run folders. Numbers in the last column refer to entries in `local-work/history/PROJECT_HISTORY.md`, when that working history is available. The rows include recorded failed, inconclusive, blocked, and parked trials alongside the successful ones.
